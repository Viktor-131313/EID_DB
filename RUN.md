# Инструкция по запуску Praktis ID Dashboard

## ⚠️ Важно: PowerShell скрипты НЕ работают в Git Bash!

Если вы используете Git Bash (MINGW64), используйте **ручной запуск** или **bash скрипт**.

## 🚀 Способ 1: Ручной запуск (рекомендуется)

### Шаг 1: Запустить бэкенд

Откройте **первый терминал** и выполните:

```bash
cd ID/backend
npm install
npm start
```

Вы должны увидеть: `Backend server running on http://localhost:3001`

**Оставьте этот терминал открытым!**

### Шаг 2: Запустить фронтенд

Откройте **второй терминал** (новое окно терминала) и выполните:

```bash
cd ID/frontend
npm install
npm start
```

Фронтенд автоматически откроется в браузере на `http://localhost:3000`

---

## 🚀 Способ 2: Использовать bash скрипт (только для Git Bash/Linux/Mac)

```bash
cd ID
chmod +x start-dev.sh
./start-dev.sh
```

---

## 🚀 Способ 3: PowerShell скрипт (только для PowerShell)

Откройте **PowerShell** (не Git Bash!) и выполните:

```powershell
cd ID
.\start-dev.ps1
```

---

## ✅ Проверка

1. Бэкенд должен работать на `http://localhost:3001`
   - Проверьте: откройте в браузере `http://localhost:3001/api/health`
   - Должно показать: `{"status":"ok","timestamp":"..."}`

2. Фронтенд должен открыться на `http://localhost:3000`
   - Если не открылся автоматически, откройте вручную

3. Если видите ошибку "Proxy error: ECONNREFUSED":
   - Это значит бэкенд не запущен
   - Запустите бэкенд в отдельном терминале (см. Шаг 1)

---

## 🔧 Устранение проблем

### Ошибка: "Proxy error: Could not proxy request"
**Причина**: Бэкенд не запущен  
**Решение**: Запустите бэкенд в отдельном терминале (см. Шаг 1)

### Ошибка: "command not found" при запуске скрипта
**Причина**: Используете неправильный терминал  
**Решение**: 
- Для `.ps1` - используйте PowerShell
- Для `.sh` - используйте Git Bash/Linux/Mac
- Или используйте ручной запуск (Способ 1)

### Ошибка: "Port 3001 already in use"
**Причина**: Порт занят другим процессом  
**Решение**: Закройте другой процесс или измените порт в `backend/server.js`
