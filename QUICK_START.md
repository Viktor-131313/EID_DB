# Быстрый старт Praktis ID Dashboard

## 🚀 Быстрая установка

### Вариант 1: Запуск через скрипты (Windows)

```powershell
# Запустить бэкенд и фронтенд одновременно
.\start-dev.ps1
```

### Вариант 2: Ручной запуск

#### Шаг 1: Установить зависимости бэкенда
```bash
cd ID/backend
npm install
```

#### Шаг 2: Запустить бэкенд (в первом терминале)
```bash
npm start
```
Бэкенд запустится на `http://localhost:3001`

#### Шаг 3: Установить зависимости фронтенда (в новом терминале)
```bash
cd ID/frontend
npm install
```

#### Шаг 4: Запустить фронтенд
```bash
npm start
```
Фронтенд откроется автоматически на `http://localhost:3000`

## ✅ Проверка работы

1. Откройте браузер на `http://localhost:3000`
2. Нажмите "Добавить объект"
3. Заполните форму и сохраните
4. Объект появится на дашборде
5. Кликните на объект для редактирования

## 📝 Структура данных

Каждый объект содержит:
- `name` - Название объекта
- `description` - Описание
- `totalActs` - Всего актов (базовое количество)
- `generatedActs` - Сгенерировано актов
- `sentForApproval` - Отправлено на согласование
- `approvedActs` - Согласовано
- `rejectedActs` - Отклонено

Проценты рассчитываются автоматически:
- Сгенерировано % = (generatedActs / totalActs) * 100
- Отправлено % = (sentForApproval / generatedActs) * 100
- Согласовано % = (approvedActs / sentForApproval) * 100
- Отклонено % = (rejectedActs / sentForApproval) * 100

## 🔧 API Endpoints

- `GET /api/objects` - Список всех объектов
- `POST /api/objects` - Создать объект
- `PUT /api/objects/:id` - Обновить объект
- `DELETE /api/objects/:id` - Удалить объект
- `GET /api/stats` - Общая статистика
- `GET /api/health` - Проверка здоровья сервера

## 💾 Хранение данных

Данные хранятся в файле `ID/backend/data/objects.json`

Файл создается автоматически при первом запуске сервера.
