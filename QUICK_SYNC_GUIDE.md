# Быстрое руководство: Синхронизация Aikona на продакшене

## 🎯 Проблема

На Render все объекты получают таймауты при синхронизации с Aikona API, но локально все работает.

## ✅ Решение (используем локальную синхронизацию)

### Шаг 1: Установите переменную окружения

Откройте PowerShell или командную строку и выполните:

```powershell
$env:AIKONA_API_KEY="f48941fd-ab51-4edd-b1f2-f202597c9920"
```

**Или для постоянной установки (системная переменная):**
1. Нажмите `Win + R`, введите `sysdm.cpl`, нажмите Enter
2. Перейдите на вкладку "Дополнительно"
3. Нажмите "Переменные среды"
4. В разделе "Переменные пользователя" нажмите "Создать"
5. Имя: `AIKONA_API_KEY`
6. Значение: `f48941fd-ab51-4edd-b1f2-f202597c9920`
7. Нажмите OK

### Шаг 2: Проверьте URL продакшена

Откройте файл `ID/scripts/sync-aikona-local.js` и проверьте строку 24:

```javascript
const PRODUCTION_URL = 'https://eid-praktis-id.onrender.com'; // Замените на ваш URL
```

Если ваш URL отличается - исправьте его.

### Шаг 3: Запустите скрипт синхронизации

Откройте PowerShell или командную строку в корне проекта и выполните:

```powershell
cd ID
node scripts/sync-aikona-local.js
```

### Что делает скрипт:

1. 📥 **Скачивает данные с Render** через API
2. 🔄 **Синхронизирует локально** (используя рабочее локальное соединение с Aikona API)
3. 📤 **Загружает обновленные данные обратно на Render** через API

### Шаг 4: Проверьте результаты

Скрипт выведет:
- Сколько объектов успешно синхронизировано
- Какие объекты имеют ошибки (если есть)
- Итоговую статистику

## ⚠️ Важные замечания

1. **Скрипт безопасен** - он не выполняется автоматически при деплое
2. **Данные сохраняются на Render** - все обновления попадают в БД Render
3. **Требуется локальное соединение** - скрипт должен запускаться с компьютера, где работает соединение с Aikona API

## 🐛 Решение проблем

### Ошибка: "AIKONA_API_KEY не установлен"

**Решение:** Установите переменную окружения (см. Шаг 1)

### Ошибка: "Ошибка при скачивании /api/containers"

**Решение:** 
- Проверьте, что URL продакшена правильный
- Проверьте, что сервис на Render запущен и доступен
- Проверьте интернет-соединение

### Ошибка: "Ошибка синхронизации объекта"

**Решение:**
- Проверьте, что Aikona API доступен локально
- Проверьте, что ID объекта в Айконе правильный
- Проверьте логи для детальной информации

## 📝 Логи

Все логи выводятся в консоль. Скрипт показывает:
- Прогресс синхронизации каждого объекта
- Результаты синхронизации
- Ошибки (если есть)
