# Проверка: Сохранение данных при деплое

## ✅ Хорошие новости!

Ваши данные **БУДУТ сохранены** при деплое, потому что:

1. **Файлы данных НЕ в `.gitignore`** (строка закомментирована)
2. **Файлы уже скачаны** в `backend/data/`
3. **Нужно только добавить их в git**

## 📋 Что нужно сделать:

### Шаг 1: Проверьте, что файлы есть

```bash
cd ID
ls backend/data/*.json
```

Должны быть:
- `objects.json`
- `tasks.json`
- `snapshots.json`

### Шаг 2: Добавьте файлы в git

```bash
cd ID
git add backend/data/objects.json
git add backend/data/tasks.json
git add backend/data/snapshots.json
```

Или одной командой:
```bash
git add backend/data/*.json
```

### Шаг 3: Проверьте статус

```bash
git status
```

Должны увидеть файлы в разделе "Changes to be committed"

### Шаг 4: Закоммитьте

```bash
git commit -m "Backup: Данные с продакшена перед деплоем"
```

### Шаг 5: Запушьте

```bash
git push
```

### Шаг 6: Деплой

После пуша Render.com автоматически задеплоит изменения, и данные будут на продакшене!

---

## ⚠️ Важно:

- **Файлы данных должны быть в репозитории** (не в `.gitignore`)
- После деплоя данные автоматически восстановятся из репозитория
- Если что-то пошло не так, можно откатить коммит с бэкапом

---

## 🔍 Проверка после деплоя:

1. Откройте приложение на продакшене
2. Проверьте наличие контейнеров
3. Проверьте наличие задач для разработки
4. Если что-то не так, проверьте логи на Render.com
