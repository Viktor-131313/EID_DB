# 🚨 СРОЧНОЕ ВОССТАНОВЛЕНИЕ ДАННЫХ

## Проблема
Данные с продакшена были перезаписаны старыми данными из репозитория при деплое.

## ⚠️ ВАЖНО: Данные уже потеряны на продакшене?

Если Render.com уже перезаписал файлы - данные могут быть потеряны. Но есть варианты восстановления:

### Вариант 1: Проверить, есть ли данные еще в Render
1. Попробуйте зайти в Render.com Dashboard
2. Откройте Shell (если доступен)
3. Проверьте файлы в `/app/backend/data/`
4. Если файлы есть - скопируйте их

### Вариант 2: Проверить git историю
Может быть данные были в предыдущем коммите?

```bash
cd ID
git log --all --oneline -- backend/data/objects.json
git show <commit-hash>:backend/data/objects.json
```

### Вариант 3: Проверить локальные файлы
Может быть вы скачали данные локально раньше?

```bash
cd ID/backend/data
# Проверьте размеры файлов - если они большие, значит там есть данные
dir objects.json tasks.json snapshots.json
```

### Вариант 4: Восстановить из бэкапа Render
Render иногда делает автоматические бэкапы. Проверьте в Dashboard.

---

## 📋 План действий:

1. **ПРОВЕРЬТЕ локальные файлы** - может данные были скачаны ранее
2. **ПРОВЕРЬТЕ git историю** - может данные были в коммите до последнего
3. **ПОПРОБУЙТЕ восстановить через Render Shell** (если доступен)
4. **Если ничего не помогает** - данные потеряны, нужно будет заново вводить
