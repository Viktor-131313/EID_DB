# 🚨 КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Колонка task_manager_link отсутствует в БД

## Проблема

В логах видно: `[saveTasks] hasTaskManagerLink: false`

Это означает, что **колонка `task_manager_link` не существует в базе данных**, поэтому `taskManagerLink` не сохраняется, даже если данные отправляются на сервер правильно.

## Решение

Добавлена проверка и автоматическая миграция в функцию `saveTasks`, которая:
1. Проверяет существование колонки `task_manager_link`
2. Создает колонку, если она не существует
3. Затем продолжает сохранение задач

## Что нужно сделать

1. **Закоммитьте и запушьте изменения:**
   ```bash
   git add .
   git commit -m "Fix: добавлена автоматическая миграция task_manager_link в saveTasks"
   git push
   ```

2. **После деплоя проверьте логи на Render:**
   - Должно появиться: `[saveTasks] Миграция task_manager_link проверена/выполнена`
   - Должно появиться: `[saveTasks] hasTaskManagerLink: true` (вместо false!)

3. **Попробуйте снова сохранить ссылку на таск-менеджер**

4. **Проверьте, что данные сохраняются:**
   - В логах должно быть: `[saveTasks] Task X: saved taskManagerLink = <ваша ссылка>`
   - После обновления страницы поле должно быть заполнено
   - Кнопка с иконкой должна появиться в таблице задач

## Почему это произошло?

Миграция в `initializeDatabase` выполняется только при инициализации базы данных. Если база данных уже была создана до добавления миграции, колонка не была создана. Теперь миграция выполняется также при каждом сохранении задач, что гарантирует наличие колонки.
