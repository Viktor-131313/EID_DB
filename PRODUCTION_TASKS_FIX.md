# 🔧 Исправление проблемы с задачами на продакшене

## Проблема

После деплоя на Render.com:
- Пропал весь список задач для разработки
- При попытке добавить задачу - ошибка 500

## Причины

1. **Колонка `task_number` была `NOT NULL`**, но код передавал `null` при создании задачи без номера
2. **Колонка `task_manager_link` могла не существовать** в базе данных на продакшене

## ✅ Исправления

### 1. Схема базы данных
- Изменено `task_number INTEGER NOT NULL` → `task_number INTEGER` (nullable)

### 2. Миграции
- Добавлена автоматическая миграция для изменения `task_number` на nullable
- Добавлена автоматическая миграция для создания `task_manager_link` (уже была)

### 3. Обработка ошибок
- Улучшена обработка ошибок при сохранении задач
- Добавлена проверка существования колонки `task_manager_link` перед использованием
- Добавлено детальное логирование ошибок

## 🔄 Что нужно сделать

### На Render.com:

1. **Перезапустите сервис** (или подождите автоматического перезапуска после деплоя)
   - Миграции выполнятся автоматически при старте сервера

2. **Проверьте логи** на Render:
   - Должны быть сообщения:
     - `✅ Миграция task_number (nullable) проверена/выполнена`
     - `✅ Миграция task_manager_link проверена/выполнена`

3. **Попробуйте создать задачу снова**

### Если проблемы остались:

1. Проверьте логи на Render - там будет детальная информация об ошибке
2. Убедитесь, что база данных подключена (проверьте `DATABASE_URL` в Environment Variables)
3. Если нужно, выполните миграцию вручную через SQL консоль на Render

## 📝 SQL для ручной миграции (если нужно)

Если автоматическая миграция не сработала, выполните вручную:

```sql
-- Сделать task_number nullable
ALTER TABLE tasks ALTER COLUMN task_number DROP NOT NULL;

-- Добавить task_manager_link (если еще нет)
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS task_manager_link TEXT;
```
