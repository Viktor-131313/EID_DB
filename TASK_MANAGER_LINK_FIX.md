# 🔧 Исправление проблемы с сохранением ссылки на таск-менеджер

## Проблема

При попытке сохранить ссылку на таск-менеджер при обновлении задачи возникала ошибка 500 (Internal Server Error).

## Причины

1. Пустые строки для `taskManagerLink` не обрабатывались корректно
2. Отсутствовала проверка типа данных перед вызовом `.trim()`
3. Недостаточное логирование ошибок для диагностики

## ✅ Исправления

### 1. Обработка пустых строк
- Пустые строки теперь преобразуются в `null`
- Добавлена проверка типа перед использованием `.trim()`

### 2. Улучшенное логирование
- Добавлено детальное логирование ошибок в endpoint обновления задачи
- Ошибки теперь включают `details` с сообщением об ошибке

### 3. Безопасная обработка данных
```javascript
taskManagerLink: req.body.taskManagerLink !== undefined 
    ? (req.body.taskManagerLink && typeof req.body.taskManagerLink === 'string' && req.body.taskManagerLink.trim() !== '' 
        ? req.body.taskManagerLink.trim() 
        : null)
    : (tasks[index].taskManagerLink || null)
```
