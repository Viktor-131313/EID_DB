# 🚀 Миграция на PostgreSQL - Решение проблемы с потерянными данными

## Проблема

На бесплатном тарифе Render.com файловая система эфемерная:
- ❌ Все изменения в JSON файлах теряются при пробуждении сервиса
- ❌ Нужно постоянно пулить/пушить данные вручную
- ❌ Неудобно для production использования

## ✅ Решение: PostgreSQL база данных

**PostgreSQL на Render.com:**
- ✅ Бесплатная (до 1 ГБ)
- ✅ Данные сохраняются постоянно
- ✅ Не теряются при пробуждении/перезапуске
- ✅ Профессиональное решение для production

## 📋 План миграции

### Шаг 1: Создать PostgreSQL базу данных на Render.com

1. Зайдите на https://dashboard.render.com
2. Нажмите **"New +"** → **"PostgreSQL"**
3. Настройте:
   - **Name:** `eid-praktis-id-db` (или любое имя)
   - **Database:** `eid_db` (или любое имя)
   - **User:** автоматически сгенерируется
   - **Region:** тот же, что у Web Service (для скорости)
   - **PostgreSQL Version:** 15 (последняя стабильная)
   - **Plan:** Free (1 ГБ)
4. Нажмите **"Create Database"**
5. **Скопируйте Internal Database URL** (он будет типа: `postgres://user:pass@host:5432/dbname`)

### Шаг 2: Подключить базу данных к Web Service

1. Зайдите в настройки вашего Web Service на Render.com
2. Перейдите в **"Environment"**
3. Добавьте переменную:
   - **Key:** `DATABASE_URL`
   - **Value:** вставьте Internal Database URL (скопированный на шаге 1)
4. Сохраните

### Шаг 3: Установить зависимость PostgreSQL

## 🔧 Структура базы данных

### Таблицы:

1. **containers** - контейнеры объектов
2. **objects** - объекты
3. **acts** - акты (сгенерированные, отправленные, согласованные, отклоненные, подписанные)
4. **tasks** - задачи разработки
5. **snapshots** - снимки статистики
