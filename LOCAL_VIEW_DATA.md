# Как увидеть скачанные данные в локальном дашборде

## ✅ Файлы успешно скачаны!

Ваши данные находятся в:
- `ID/backend/data/objects.json` - контейнеры и объекты
- `ID/backend/data/tasks.json` - задачи для разработки  
- `ID/backend/data/snapshots.json` - снимки статистики

## 📋 Что делать дальше:

### Вариант 1: Просто добавить в Git и задеплоить (Рекомендуется)

Данные уже скачаны локально. Просто добавьте их в репозиторий:

```bash
cd ID
git add backend/data/*.json
git commit -m "Backup: Данные с продакшена"
git push
```

После деплоя данные автоматически появятся на продакшене.

---

### Вариант 2: Посмотреть данные локально

Чтобы увидеть данные в локальном дашборде:

**Шаг 1: Запустите backend**

```bash
cd ID/backend
npm install  # если еще не установлены зависимости
npm start    # или node server.js
```

Backend запустится на `http://localhost:3001`

**Шаг 2: Запустите frontend**

В другом терминале:

```bash
cd ID/frontend
npm install  # если еще не установлены зависимости
npm start
```

Frontend запустится на `http://localhost:3000`

**Шаг 3: Откройте браузер**

Откройте `http://localhost:3000` - данные будут видны!

---

### Вариант 3: Просто проверить файлы

Можно просто открыть файлы JSON и посмотреть содержимое:

- `ID/backend/data/objects.json` - все контейнеры и объекты
- `ID/backend/data/tasks.json` - все задачи
- `ID/backend/data/snapshots.json` - все снимки

---

## ⚠️ Важно:

**Для деплоя не нужно запускать локальный сервер!**

Просто:
1. ✅ Данные уже скачаны (вы это сделали)
2. Добавьте их в git: `git add backend/data/*.json`
3. Закоммитьте: `git commit -m "Backup: Данные с продакшена"`
4. Запушьте: `git push`
5. Render.com автоматически задеплоит, и данные появятся на продакшене

---

## 🔍 Проверка данных

Если хотите убедиться, что данные правильные:

```bash
# Проверить размер файлов (должны быть не пустые)
cd ID
ls -lh backend/data/*.json

# Посмотреть первые строки
cat backend/data/objects.json | head -20
cat backend/data/tasks.json | head -20
```
